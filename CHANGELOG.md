# Changelog

## V2.8.5

- **Magisk gets the full WebUI:** On Magisk, tapping the module Action button now opens the complete WebUI. A small helper app installs automatically on first use, and only once.
- **Magisk is now fully supported:** KernelSU, APatch, and Magisk all offer the same WebUI experience.
- **Choose local or server keyboxes per tier:** The priority list now lets you prefer keyboxes stored on your device or fetched from your servers, separately for each validity level. Your old saved order keeps working.
- **Emergency reports moved:** One-tap diagnostic archives now have their own dedicated command, since the Action button opens the WebUI.
- **Clearer guides:** Installation, Magisk, logging, and help texts rewritten in all supported languages.
